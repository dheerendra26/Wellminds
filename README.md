# 🧠 WellMinds

**WellMinds** is a static resource website built using **HTML and CSS**, focused on promoting **mental health awareness** and providing helpful information to support emotional well-being.

The platform aims to educate users, reduce stigma around mental health, and encourage positive mental health practices through accessible and easy-to-read content.

---

## 🌱 Overview

Mental health is an essential part of overall well-being. WellMinds serves as an informational hub that shares content related to mental health care, self-help strategies, and awareness topics in a simple and user-friendly format.

---

## ✨ Features

- Clean and responsive static website  
- Informational content on mental health awareness  
- Simple and calming user interface  
- Easy navigation and readable layout  
- No backend or database dependency  

---

## 🛠️ Built With

- **HTML**
- **CSS**


---

## 🎯 Purpose

This project was developed to:
- Spread awareness about mental health  
- Provide educational mental health resources  
- Practice frontend web development fundamentals  
- Promote a positive and supportive online space
